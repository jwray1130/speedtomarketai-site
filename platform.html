Settings

      
    

    

      
Model and token settings for the pipeline. The Anthropic API key is held server-side — you do not need to paste it here.


      

        
        
        
Default global model. Individual modules may override this based on reasoning / extraction preference.

      

      

        
        
Off (default): pipeline uses per-module routing — most modules run on Opus, three lighter ones run on Sonnet, classifier verification on Sonnet. On: every single LLM call (classifier, verifier, all 24 modules) goes through the model above. Force Opus 4.8 for max-quality runs (modest spend increase; the default already runs most modules on Opus). Force Sonnet 5 to test near-Opus quality at 40-60% lower list price; note its newer tokenizer bills roughly 30% more tokens for the same text, and the $2/$10 intro rate steps to $3/$15 on 9/1/26.

      

      

        
        
        
Anthropic only generates as much as the response naturally needs — this is the ceiling, not the target. Default 4096 covers most modules. Raise to 8192 or 16384 for complex Loss History tables, large Excess Towers, or detailed Discrepancy reports. Server-side limit: 16384.
